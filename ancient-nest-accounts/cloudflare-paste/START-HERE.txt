Ancient Nest 10.4 Discord sign-in

Copy PASTE-INTO-CLOUDFLARE-ASSISTANT.txt into the Cloudflare assistant, or deploy worker.js through the Worker editor with the existing DB binding. It is a bundled ES-module Worker, not a Windows executable.

For an existing database use only pending versioned migrations. In D1 Console, inspect d1_migrations and table columns first. If 0001–0004 are already applied and auth_provider is absent, run migrations/0005_discord_sign_in.sql, then record 0005_discord_sign_in.sql in d1_migrations. It revokes old device sessions once without deleting profiles. Do not repeat ALTER TABLE or replay applied migrations. For an empty database only, database-empty-only.sql creates and records all five migrations.

Set AUTH_MODE=discord, DISCORD_CLIENT_ID=1562796619722793010, the existing public URL and origins. Required server secrets: JWT_SECRET, COORDINATOR_API_KEY, DISCORD_CLIENT_SECRET and DISCORD_BOT_TOKEN for team voice. No Resend or Twilio setup is needed. Preserve existing data and secrets.

After deploying, check /health, /ready, /auth/discord/config and /discord/ready. Test Continue with Discord in the Windows client. First-time Discord consent may require approval; existing approved sessions restore automatically. There is no password/email/phone signup page.
