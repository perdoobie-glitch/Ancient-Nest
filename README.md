# Ancient Nest

Project repository for Ancient Nest.

## Current status

This is an initial repository. Game source code, the game engine, and image assets have not been added yet.

The main-menu reference supplied in the conversation is described in [docs/main-menu.md](docs/main-menu.md). The reference image itself is not included in this repository.

## Structure

- `docs/`: design notes and requirements.
- `assets/`: project artwork and other assets.
- `src/`: game source code.

## Next step

Add the game project and its reference artwork, then implement the main menu in the project's game engine.
